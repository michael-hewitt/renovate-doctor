# renovate-doctor

When a Renovate PR fails CI, an agent fixes and merges it, reruns it, or declines it with a trip wire. Reusable GitHub Actions workflow.

**Status: under construction.** Nothing is tagged yet and the workflow does not exist. The design is in [issue #1](https://github.com/michael-hewitt/renovate-doctor/issues/1) and the contracts between the pieces are in [docs/architecture.md](docs/architecture.md).
